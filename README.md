## Important: image quality

The JPEG image files in `assets/images/` are byte-for-byte copies of the uploaded originals. They were **not** re-saved, compressed, sharpened, AI-upscaled, face-edited, or regenerated. `SHA256SUMS.txt` records their checksums.

## Upload to GitHub

Upload the **contents** of this folder to the repository root while preserving the folders. GitHub should end up with:

```text
/index.html
/fr/index.html
/ht/index.html
/assets/site.css
/assets/site.js
/assets/images/...
```

If GitHub Pages is enabled for the `main` branch and root folder, `index.html` becomes the homepage automatically.
