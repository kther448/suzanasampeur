## Upload to GitHub
Upload the contents of this folder to the repository root. Keep the directory structure exactly as supplied. The website references images from `assets/images/`.

## Photography
All supplied photography is preserved at its original uploaded resolution. The build does not regenerate faces, apply AI image edits, or recompress the photographs. CSS only crops images visually where appropriate. Transaction flyers use `object-fit: contain` so text and property details are not cropped.
